# Geldjacht H2

Speurtocht-game voor economie 2 mavo, hoofdstuk 2 "Jij en je geld".

- Spel: https://jboersen88-dot.github.io/geldjacht-h2/
- Docent: https://jboersen88-dot.github.io/geldjacht-h2/docent.html
- `vragen.js`: vragenbank (open vragen + rekenvragen met wisselende getallen)
- `fotos.js`: volgorde waarin de stukjes van elke foto zichtbaar worden
- `worker/`: Cloudflare Worker voor codes, pestkaarten en ranglijst (geheime sleutel en pincode staan als secret in Cloudflare)
- Nakijken gaat via de AI-worker van de escape room.
